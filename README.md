# Echo

Пример приложения Echo, которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `8000` |
| Путь проверки состояния | `/` |

Приложение слушает порт из переменной окружения `PORT` — её передаёт платформа, — а без неё `8000`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# установка зависимостей
go mod download

# запуск в дев режиме
go run .

# сборка для продакшн
go build -o app . && ./app
```
